# 单知识库 Agent 重构实施计划

日期：2026-09-22。依据：用户已批准中等复杂度检索图与清理范围。

目标：一个知识库 Agent，项目多会话，按需检索、证据检查、最多一次补查；保留真实资料。
架构：Vue 组件负责上传/动态事件展示；LangGraph 负责有界决策；解析/切分/检索分层。沿用当前依赖。

- [x] 数据保护：外部数据库备份；确认演示数据来源，不按“测试”名称删除真实内容。
- [x] 后端收敛：移除 Agent CRUD/配置与会话选择；迁移保留项目、消息、请求及文档，队列保留固定知识库执行身份。
- [x] 图：加载截至当前请求的会话历史；决策、检索、证据检查、补查、回答、引用检查；仅最终回答发 token；检索最多两轮，异常独立处理。
- [x] 入库：结构化解析 PDF/MD/DOCX 段落与表格、保留来源、token 预算切分和重叠；版本化索引并原子重建旧文本，未知页码不伪造。
- [x] 前端：NewProjectModal 管项目创建与失败文件重试；NewThreadModal 仅会话标题；ChatPage 管事件，ExecutionPanel 展示真实步骤及来源，不放返回按钮、不放 Tab。
- [x] 清理：删除已确认的测试/eval/演示文件和引用；不提交测试夹具。
- [x] 验收：在仓库外执行临时图分支/解析/迁移/浏览器检查，运行构建，核对真实数据后提交。

验收边界：无 OCR/旧 .doc 承诺；无无限重试；引用结构校验不是语义正确性保证；不增加多 Agent/联网检索。图内不执行远程工具；已确认原 MCP 是固定天气演示，随演示清理移除。
