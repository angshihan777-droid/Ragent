# Ragent · 项目知识库助手

FastAPI + LangGraph + PostgreSQL/pgvector + Redis + Vue 3。每个项目拥有独立资料与多个会话；只有一个知识库 Agent，无人设选择或手动 RAG 开关。

## 使用

1. `docker compose up --build -d` 启动后端。
2. 在 `web` 目录执行 `npm install`、`npm run dev` 启动界面。
3. 在模型配置页填写 OpenAI 兼容服务信息。模型须支持 JSON object 输出（response_format），不再要求强制工具选择；结构化结果由后端严格校验。
4. 创建项目并添加 PDF、Markdown、DOCX 或 TXT，进入自动创建的首个会话。

无默认项目、示例资料、演示工具或内置密钥。生产发布前需自行配置鉴权、HTTPS 和网络访问边界；当前是本地单用户应用。

## 对话图

```text
准备上下文 → 理解问题与决策
               ├─ 直接回答 / 澄清 → 回答 → 引用结构检查 → 结束
               └─ 检索与重排 → 证据检查
                                  ├─ 足够 → 回答
                                  ├─ 有可补查缺口 → 改写查询 → 检索与重排
                                  └─ 无法补足 / 到达上限 → 有限回答
```

- 检索最多两轮；相同查询、无新增证据或基础设施故障不会无限重试。
- 检索范围由后端注入项目 ID。资料不是指令，历史回复不是新的文档证据。
- 历史只取当前请求之前成功完成的问答，最多 12 轮、12000 字符预算。
- SSE 实时展示实际节点与来源；内部决策/证据检查的模型内容不显示。正文在引用结构检查及租约校验的数据库事务提交后发布，不伪装成模型逐 token 输出。
- 引用结构检查只检查来源编号，不代表已验证所有语义。匹配度是向量余弦相似度，不是答案正确率。
- 请求落库后进入 FIFO 队列；执行身份固定为 `knowledge-base`。worker 保留租约、心跳与超时恢复。

## RAG 入库与检索

- PDF 按页提取并记录页码；无文本页显式拒绝，需先 OCR。
- Markdown 保留标题路径与代码块边界；DOCX 按正文顺序读取段落/表格，表格行带表头。
- 结构化块按实际 embedding tokenizer 切分，目标最多 384 tokens（含标题），长块最多重叠 48 tokens，句子边界优先。
- 保存标题路径、页码（若已知）、块序号和相对合并块的文本偏移。
- 向量召回 20 个候选，再 cross-encoder 重排取 3 个；长重排查询限制为 96 tokens，最多两轮的来源合并去重。
- embedding 与重排模型缓存使用共享 Docker 卷，重建容器不重复下载权重。
- 单文件最大 20 MB，支持 `.pdf/.docx/.md/.markdown/.txt`；不支持旧 `.doc`、OCR 或图片理解。

旧索引不会在服务启动时偷偷重算。备份数据库、暂停写入后执行：

```powershell
docker compose exec api python -m app.reindex
```

按文档原子替换索引并记录版本，重复执行不会重复重建。旧文档仅存纯文本时，保持原始正文，不伪造丢失的页码或表格。需要这些定位信息时，请重新上传原始文件。

## 界面与维护

左栏项目 → 多会话，中间对话，右栏上下双卡片：执行过程 / 命中资料与匹配度。不使用 Tab。两侧可折叠与调整宽度，右栏无返回对话按钮。

新项目创建与首个会话同事务完成。选择文件后自动填入默认项目名，点击“创建并上传”开始逐文件入库；失败重试保留项目及已成功文件，只重试未完成项。

项目资料页与知识库图书馆共用资料管理组件，均可搜索、查看入库正文、编辑及删除。图书馆可按项目筛选，选定具体项目后可上传或新建文本。删除前确认，正文与检索片段同步删除；编辑使用版本校验避免覆盖他人的修改，向量生成成功后才原子替换正文和索引。仅修改标题保留原有页码与结构；修改正文后按文本重新切分，不伪造原文件定位。

打开应用或切换项目默认显示空白对话入口，不自动打开旧会话；历史仍保留在左栏，需手动选择。可随时新建对话，删除当前会话不会自动打开另一段历史。

产品运行时不加载测试/演示资料。按后续验收要求，`evaluation/` 单独保留合成检索语料、隔离故障注入脚本和真实运行记录；评测使用临时数据库及独立 Redis 队列，不向真实项目插入资料。复现方式见 `evaluation/README.md`，结果与限制见 `evaluation/REPORT.md`。
